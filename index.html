Install Soar

A mobile UI engine with a Rust core. Write apps in TSX, run them on the GPU.

1Install the command line tools

One command installs soar and the soar-desktop host it runs apps in, plus the VS Code extension when VS Code is installed. Rerun it to update.

curl -fsSL https://kakashi250802.github.io/soar-install/install.sh | sh

It installs to ~/.soar/bin and prints the line that adds it to your PATH. Then open a new terminal and check:

soar --version

In PowerShell:

irm https://kakashi250802.github.io/soar-install/install.ps1 | iex

It installs to %USERPROFILE%\.soar\bin and adds it to your PATH. Open a new terminal and run soar --version.

Prefer to download by hand? Every file is on the latest release: unpack the archive for your platform and keep soar and soar-desktop in the same folder.

2Set up VS Code

The Soar extension gives .soar files highlighting, type checking against the Soar SDK, @/ imports, auto import and a file icon. The install script adds it when the code command exists; otherwise download soar-vscode.vsix from the release and pick Extensions → … → Install from VSIX.

  • Also install Prettier: projects made by soar new format .soar files on save with it.
  • Reload VS Code after installing (Developer: Reload Window).

3Create and run an app

soar new my-app
cd my-app
soar start

soar start opens the app in a desktop window. Edit src/App.soar while it runs: it reloads in place and keeps its state.

CommandWhat it does
soar new DIRCreates a project: soar.json, src/App.soar, SDK types and editor settings.
soar startRuns the app on the desktop with hot reload.
soar checkCompiles and verifies the app, with errors as file:line:column.
soar build -o app.soarbCompiles the app to a bundle.
soar devtoolsOpens a browser DevTools for the running app: console, elements, network, state.

What the download covers

The download runs apps on the desktop. Running on a phone (soar run ios, soar run android) still builds the native hosts from the Soar engine source, which is not public yet.

Troubleshooting

soar: command not found

The install folder is not on your PATH yet. Run the export PATH=… line the script printed, or open a new terminal after adding it to your shell profile.

macOS says the app “cannot be opened”

The binaries are not notarized yet. The install script avoids the warning; for a manual download, clear the quarantine flag once:

xattr -d com.apple.quarantine soar soar-desktop

A specific version

curl -fsSL https://kakashi250802.github.io/soar-install/install.sh | SOAR_VERSION=v0.1.0 sh

Uninstall

Delete ~/.soar (Windows: %USERPROFILE%\.soar), remove it from your PATH, and uninstall the Soar extension in VS Code.
